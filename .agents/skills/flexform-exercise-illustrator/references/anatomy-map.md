# Exercise anatomy map

Use this reference to prevent broad or decorative muscle coloring. Primary muscles receive the strongest highlight; secondary muscles use the same hue at lower intensity.

| Movement family | Primary | Common secondary |
|---|---|---|
| Horizontal press | Pectoralis major | Anterior deltoids, triceps |
| Incline press | Clavicular pectoralis | Anterior deltoids, triceps |
| Vertical press | Anterior and lateral deltoids | Triceps, upper chest |
| Chest fly | Pectoralis major | Anterior deltoids |
| Vertical pull | Latissimus dorsi | Biceps, teres major, lower traps |
| Horizontal row | Rhomboids, middle traps | Lats, posterior deltoids, biceps |
| Rear-delt pull | Posterior deltoids | Rhomboids, middle traps, external rotators |
| Squat | Quadriceps | Gluteus maximus, adductors, trunk |
| Lunge / split squat | Quadriceps or gluteus maximus by stance | Adductors, hamstrings |
| Hip hinge | Hamstrings | Gluteus maximus, spinal erectors |
| Hip thrust / bridge | Gluteus maximus | Hamstrings, adductors |
| Knee extension | Quadriceps | None |
| Knee flexion | Hamstrings | Gastrocnemius |
| Calf raise | Gastrocnemius and soleus | None |
| Elbow flexion | Biceps or brachialis by grip | Brachioradialis, forearms |
| Elbow extension | Triceps | None |
| Trunk flexion | Rectus abdominis | Obliques, hip flexors by exercise |
| Anti-extension | Rectus abdominis and deep core | Glutes, serratus anterior |

## Accent system

- push and chest-dominant: blue `#1269d3`
- quad-dominant lower body: green `#21844a`
- pull and back-dominant: purple `#6838a6`
- posterior chain: orange `#ec5a18`

When an exercise belongs to a neutral whole-body category, retain the nearest movement-family accent instead of inventing a new palette.
